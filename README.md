# Nike Financial Analysis & Forecast Model

## Project Overview

This project analyzes Nike's historical financial performance from FY2021 to FY2025 and develops a three-year financial forecast through FY2028.

The project includes:

- Historical financial analysis
- Ratio analysis
- Financial forecasting
- Scenario analysis
- Dashboard visualizations
- Analyst memo

---

## Skills Demonstrated

- Financial Statement Analysis
- Financial Modeling
- Forecasting
- Scenario Analysis
- Excel
- Business Analysis
- Data Visualization

---

## Key Findings

- Revenue grew from FY2021 through FY2024 before declining in FY2025.
- Operating Margin fell from 15.6% to 8.0%.
- Net Income declined significantly in FY2025.
- Free Cash Flow weakened over the period.
- Base-case forecast projects revenue of approximately $55.2 billion by FY2028.
